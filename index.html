1. One observation boundary

The operator owns the task, recipient, source permissions and approved public snapshots. The coding agent requests a source handle or submits probe code.

Smaller, simpler runtime

One typed question, selected by modality; no generated explanation, automatic redaction retry or relevance cascade. Explicit source caps and public hashes skip inference.

Closed on uncertainty

Incomplete captures, invalid images, missing inference and malformed scores withhold the view. Modified released text or image payloads fail validation.

Withheld reads return configured next steps. Exact repeated scores can be cached for 30 seconds with a 128-entry bound; cache keys bind the full context, session and observation. No raw records are stored in the cache. Every release still gets a fresh capability. Unicode and encoded identifiers receive bounded checks, and unknown message roles or extra fields are rejected.

Default sources are local. Conditional display requires an operator grant. A score of 0.98 is a threshold, not a calibrated 98% safety guarantee.

2. How the agent works with it

Get permitted context

gateway_sources lists registered handles. gateway_read("setup") returns the approved task and schema.

Request a data view

gateway_read("records") returns local. It does not open the protected file just to reject the view.

Compute without displaying rows

gateway_compute(["records"], code) runs Python with read-only inputs and no network. Captured output is reviewed too.

Keep artifacts local

Save under /outputs. The agent gets a random receipt; the operator can verify the private artifact. A receipt alone does not prove success.

Example tool response

{
  "action": "local",
  "reason": "source_local_only",
  "text": "[Gateway] Content withheld. Write a local probe...",
  "next_steps": [
    {"tool": "gateway_read", "arguments": {"source_id": "setup"}},
    {"tool": "gateway_compute", "source_ids": ["records"]}
  ]
}

3. Completed comparisons and live agent tasks

5,432 new views across 35 scenario families and 1,084 document/world groups. Inputs include public MBPP code/tests and MedQuAD medical reference material, fictional record overlays, schemas, errors, encodings, prompt injection, history changes and screenshots.

No training. Four question formats were compared on 382 development views. The chosen text question asks whether disclosure would violate policy. A regression failure then caused the image route to retain the original permission question. The 0.98 threshold and 0.8B weights remain unchanged. Efficiency

New-set model calls fell from 3771 to 3514 through stronger deterministic checks. Warm inspected decisions at six workers: 78 ms p50 / 150 ms p95 on one A100.

For a serial exact-repeat workload, median latency fell from 30.31 ms to 0.47 ms; 41 requests used one model call with caching instead of 41.

The cache result applies to identical repeated requests; it is not a general traffic hit rate or latency guarantee.

Robustness

74 tests and 1,280 generated contract trials passed. Checks cover exact release bytes, context/session changes, cache expiry, malformed scores, Unicode/encoding vetoes, source paths, MCP transport and sandbox isolation.

Across the final new, regression and fresh-image sets, 5,016/5,016 prohibited views were withheld. Cases share templates and paired contexts; this observed result is not a universal safety guarantee.
